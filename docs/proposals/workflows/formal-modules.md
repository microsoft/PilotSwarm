# Formal module inventory

This file answers which TLA+ modules exist and where their safety and progress predicates are defined. For example, `WfContinuedSession` checks that a result belongs to its own visit and that owed session ends are eventually sent.

Source: `4fa702dc8b078b93c3e26339dc833b53d8acfee4`. All modules under `docs/formal/workflow/` and `docs/formal/session-orchestration/` are included. The [formal model guide](tests-and-models.md#formal-models) explains correspondence and evidence limits. Predicates below are defined in each module; wrappers can inherit through `EXTENDS` or `INSTANCE`. Zero entry configurations does not mean an unused module. Recorded group results are explicitly group results, not an invented per-module or current-head pass. The linked source README is the evidence for each result summary. The [configuration summary](formal-configurations.md) gives per-module counts and links the source tables for exact active and retired settings.
