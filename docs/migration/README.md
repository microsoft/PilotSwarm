# PilotSwarm history import

This repository combines the original `affandar/PilotSwarm` Git history with the
Microsoft `pilotswarm` starter repository. The merge retains both parent histories.

The root `LICENSE`, `README.md`, and `SECURITY.md` are the versions from the
Microsoft starter repository at the time of import. Their original PilotSwarm
counterparts are retained here for reference:

- [Original MIT license and copyright notice](LICENSE-original-MIT.md)
- [Original project README](README-original.md)
- [Original security policy](SECURITY-original.md)

The original MIT license is labelled historical here to distinguish its
copyright notice from the Microsoft starter repository's root `LICENSE`.
The root `CODE_OF_CONDUCT.md` and `SUPPORT.md` also remain from the Microsoft
starter repository. Both sets of original commits are available in Git history.
