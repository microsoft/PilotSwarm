# Source provenance

PilotSwarm originated in
[affandar/PilotSwarm](https://github.com/affandar/PilotSwarm) under the MIT
License, copyright 2026 Affan Dar and contributors. It was imported into
[microsoft/PilotSwarm](https://github.com/microsoft/PilotSwarm) in September
2026 and combined with Microsoft's repository/community files.

The last imported source release was **0.5.79**, upstream commit
`7cac3109` (the preceding import contained **0.5.78**, commit `2b638c37`).
This record preserves attribution without requiring the imported branch and
tag history to be published. The root and package-local `LICENSE` files retain
both the original-contributor and Microsoft copyright and permission notices.

The first Microsoft release, **v0.6.0**, was qualified and published from source
commit `84d2d2a7474ba70cbbc6fdccc0a1062c50a06982`. Its package tarballs and
`SHA256SUMS` remain immutable. A supplemental `LICENSE` release asset supplies
the complete notice omitted from those original tarballs; later packages
include that notice inside each tarball as well.

History cleanup must not be confused with software changes: retain explicit
old-to-new source provenance if release refs are ever re-anchored, and never
claim a new commit SHA was the original tested release SHA. Removing branches
or rewriting Git refs alone does not purge GitHub's retained PR refs or cached
objects; maintainers must complete any required GitHub Support cleanup before
declaring private historical material inaccessible.
