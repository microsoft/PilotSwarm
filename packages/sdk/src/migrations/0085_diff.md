# Diff for migration 0085

Migration: `migrations/session-steering-enablement-0085.ts` — `sessionSteeringEnablementMigration`.
Reason: review finding ST-M04 (D-23, NFR-13): `sessions.steering` could be enabled while a live
worker could not run steering; and §11 runtime counters were trace-only. 0082 is frozen.

## Table and index changes

None. Counters reuse `session_steering_counters` (0082).

## New functions

| Function | Purpose |
|---|---|
| `cms_steer_incapable_workers()` | JSON array of live, non-draining worker ids whose `info.capabilities["sessions.steering"]` is not `true`. Live = `updated_at` younger than max(90 s, 3 × the worker's reported `state["system-agents"].heartbeatMs`), the management client's live-worker rule. |
| `cms_feature_mutate_gated(...)` | Same 11 arguments as `cms_feature_mutate` (0077). Enabling `sessions.steering` (enabled = true, not an unset, either scope) raises `FEATURE_CONFLICT: sessions.steering cannot be enabled while N live worker(s) do not run a steering-capable build` when `cms_steer_incapable_workers()` is not empty, in the same statement as the write. Otherwise calls `cms_feature_mutate` unchanged. Disables and other keys pass through. |
| `cms_steer_add_counters(p_session_id, p_counts)` | Adds non-negative integer counters to `session_steering_counters`. Names must match `^[a-z][a-z0-9_:]{0,63}$`; anything else is ignored. No content, no identities. |

`cms_feature_mutate` itself is unchanged. `FeatureStore.mutate` calls the gated function for
`sessions.steering` and fails closed with `FEATURE_CONFLICT` if it is missing.
