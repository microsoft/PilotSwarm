# Migration 0085: Authenticated MoTD history

Every authenticated viewer can list existing messages and read their pictures.
The reader list includes today's and previous messages. Scheduled messages
remain admin-only until their start time. Non-admin list results omit creator
identity and dismissal counts. Admins retain those fields.

This is an additive migration over deployed 0084. It replaces only
`cms_motd_list` and `cms_motd_image`. Create and delete retain their existing
SQL admin checks. Deleted rows and pictures remain unreadable.

The owner's read-only history decision supersedes review finding MOTD-R1's
end-of-window restriction. Previous-message pictures are now intentionally
readable for history and preview. Before-start protection is retained for
scheduled messages. Current-message selection and per-person dismissal
behavior do not change.
