### `cms_steer_mark_submitting` — body modified (baseline: 0082) — F02, F03

## F06: honest recovery timing

### Constraint `session_steering_requests_disposition_check` — replaced

Adds the disposition `delivered_timing_unconfirmed` ("Delivered — timing not recorded"): the
steer is known to be in the conversation, but no delivery kind was recorded, so neither
"Delivered to current turn" nor "Delivered after the earlier response" can be claimed.

```diff
-  CHECK (disposition IN ('accepted','delivered_current_turn','delivered_after_response','delivered_before_stop',

+  CHECK (disposition IN ('accepted','delivered_current_turn','delivered_after_response','delivered_timing_unconfirmed',
+                         'delivered_before_stop','not_delivered_turn_ended','not_delivered_turn_stopped','withdrawn','delivery_unconfirmed'))
```

### `cms_steer_delivered_disposition(p_kind)` — new

`steering` ⇒ `delivered_current_turn`; `queued`, `idle` ⇒ `delivered_after_response`;
anything else ⇒ `delivered_timing_unconfirmed`.

### `cms_steer_record_recovery_check` — signature and body modified (baseline: 0083)

The 4-argument function is dropped and replaced by one with a 5th argument,
`p_kind TEXT DEFAULT NULL` (4-argument callers resolve to it; keeping both would make those
calls ambiguous). On `present` / `present_local` the found attempt keeps any kind recorded
from live evidence, otherwise takes the validated `p_kind` (`steering`, `queued`, `idle`, else
NULL). The disposition comes from the first delivered attempt's kind through
`cms_steer_delivered_disposition`, instead of always `delivered_current_turn`. Inclusion is
unchanged: `present` ⇒ `included`, `present_local` ⇒ left to finalize.
