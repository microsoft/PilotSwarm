# Diff for migration 0083

Migration: `migrations/turn-control-0083.ts`, function `turnControlConvertMigration`, registered as `0083 turn_control_convert`.
Design: `docs/proposals/session-turn-control.md`, section "Convert a queued message" (revision 9).

**Deploy requirement (pre-release test environments only).** 0082 and 0083 ship together. Before this migration runs, stop every worker that runs the 0082 code. Such a worker calls the two-argument `cms_turn_start`, which 0083 drops: its turn start fails with `42883 undefined_function`, and the turn retries.

## Table and index changes

| Change | Detail |
|---|---|
| Columns, indexes | None. |
| Data | `UPDATE sessions SET active_turn_index = NULL WHERE active_turn_index IS NOT NULL AND turn_high = active_turn_index`. This clears the running mark of a turn that an 0082 worker started; `turn_high` stays. That turn accepts no control until its retry passes the new turn start, which records its prompt. Until then a Steer is refused `no_turn` and a Stop answers "nothing to stop". Legacy turns (`turn_high = -1`) keep their mark. |

The steer event data gains the optional key `replacesClientMessageId`.

## New functions

| Function | Role |
|---|---|
| `cms_prompt_holds_any(p_session, p_ids JSONB)` | Whether a `user.message` or `system.message` of the session, in any lifetime, holds one of the client message ids. |
| `cms_turn_replaced(p_session, p_turn DEFAULT NULL) RETURNS TEXT[]` | The `replacesClientMessageId` of the turn's steers whose outcome is `delivered`, in position order and in this lifetime. A NULL turn means `turn_high`. |

```diff
+DROP FUNCTION IF EXISTS cms_turn_start(TEXT, INT);
+CREATE OR REPLACE FUNCTION cms_turn_start(p_session TEXT, p_turn INT, p_records JSONB, p_worker TEXT)
 ...
     IF p_turn < v_high THEN
         RETURN '{"stale":true}'::jsonb;
     END IF;
+    INSERT INTO session_events (session_id, event_type, data, worker_node_id)
+    SELECT p_session, r.rec->>'eventType', r.rec->'data', p_worker
+      FROM jsonb_array_elements(COALESCE(p_records, '[]')) WITH ORDINALITY AS r(rec, ord)
+     WHERE CASE WHEN <record has a non-empty clientMessageIds array>
+                THEN NOT cms_prompt_holds_any(p_session, r.rec->'data'->'clientMessageIds')
```

The worker passes the turn's `system.message` and `user.message`. They are written in the transaction that marks the turn running, so a prompt is recorded before its turn can accept a control.

### `cms_turn_end`

The signature is unchanged.

```diff

+            WHEN <the steer has replacesClientMessageId>             THEN 'not_delivered'
```
