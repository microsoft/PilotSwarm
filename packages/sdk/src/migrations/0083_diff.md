# Diff for migration 0083

Migration: `migrations/session-steering-recovery-0083.ts` — `sessionSteeringRecoveryMigration`.
Reason: review finding (FR-13). Same-activity recovery after a lost live session resumes the
activity's own local files, not the stored base. A steer found there is delivered, but it is not
yet in any saved conversation. 0082 is frozen (deployed), so the fix is a new migration.

### `cms_steer_record_recovery_check` — body modified (baseline: 0082)

Adds the result `present_local`. The row becomes `delivered` (its attempt gets the delivery
evidence) and is not resent, but `included` is left unchanged: inclusion comes from finalize,
because the pump lists the request in this attempt's manifest (published ⇒ included,
unpublished ⇒ not included). `present` keeps its 0082 meaning: the id is in the conversation
restored from the stored base, so the row is included at once.
