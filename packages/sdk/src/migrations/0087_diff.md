## Stop label on the cancellation path

### `cms_steer_turn_finalize` — signature and body modified (baseline: 0082; unchanged by 0083-0086)

The 8-argument function is dropped and replaced by one with a 9th argument, `p_close BOOLEAN
DEFAULT true` (8-argument callers resolve to it). With `p_close = false` the procedure records
inclusion exactly as before and returns `{ finalized: false, reason: 'left_open', inclusionUpdated }`
without closing the target. A runTurn activity that was cancelled (Stop won the orchestration
race, or the session was cancelled) passes false, so the canceller's own closure — Stop's
`session.turn_stopped` close, a terminal-state or delete backstop, or the next window open — labels
the rows (`stopped` for Stop) instead of an earlier `turn_ended`.

```diff
-    p_outcome TEXT, p_manifest TEXT[], p_snapshot_version INT)
+    p_outcome TEXT, p_manifest TEXT[], p_snapshot_version INT, p_close BOOLEAN DEFAULT true)
@@
     IF w.state = 'closed' THEN
         RETURN jsonb_build_object('finalized', false, 'reason', 'closed', 'inclusionUpdated', v_n);
     END IF;
+    IF NOT COALESCE(p_close, true) THEN
+        RETURN jsonb_build_object('finalized', false, 'reason', 'left_open', 'inclusionUpdated', v_n);
+    END IF;
```
