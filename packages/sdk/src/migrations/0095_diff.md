# Migration 0095: Ten canvas slots

Widens the slot check on the four canvas tables from 1-5 to 1-10:
`session_canvases` (0045), `canvas_live` (0047), `canvas_share_links` (0048)
and `canvas_kv` (0064).

Each existing slot check is found in `pg_constraint` by its column, dropped,
and replaced by one check named `<table>_slot_range`:
`CHECK (slot BETWEEN 1 AND 10)`. No constraint name is assumed.

Existing rows hold slots 1-5 and stay valid. No row, function, index or
grant changes. The range is never narrowed again: rows in slots 6-10 would
violate a narrower check.

Migrations 0045, 0047, 0048 and 0064 are not edited.
