# Diff for migration 0084 — `canvas_app_registry`

Migration file: `migrations/canvas-app-registry-0084.ts` — `canvasAppRegistryMigration`.
Issue 181: canvas apps get an owned, scoped, versioned registry in the CMS.

Everything here is new. No existing table or function is changed, so this
diff lists only additions.

## Table changes

### `canvas_apps` — new

| Column | Type | Notes |
|---|---|---|
| `app_id` | TEXT PK | |
| `name` | TEXT NOT NULL | slug |
| `scope` | TEXT NOT NULL | `shared` or `user` |
| `owner_provider`, `owner_subject` | TEXT | required for `user`; NULL only for admin-migrated legacy shared apps |
| `description` | TEXT NOT NULL DEFAULT '' | |
| `tags` | TEXT[] NOT NULL DEFAULT '{}' | |
| `enabled` | BOOLEAN NOT NULL DEFAULT TRUE | |
| `active_version_id` | TEXT | |
| `import_open` | BOOLEAN NOT NULL DEFAULT FALSE | an import created the app and has not finished |
| `artifact_session_id` | TEXT NOT NULL UNIQUE | the app's own byte space |
| `created_by`, `created_at`, `updated_at` | | |

Indexes: `canvas_apps_shared_name_uniq (name) WHERE scope='shared'`;
`canvas_apps_user_name_uniq (owner_provider, owner_subject, name) WHERE scope='user'`
(the same shape as agent packages since 0043).

### `canvas_app_versions` — new

`version_id` PK, `app_id` FK → `canvas_apps` ON DELETE CASCADE, `version` (the
publisher's SemVer text), `precedence_key TEXT COLLATE "C"`, `state`
(`pending`|`ready`), `sha256`, `size_bytes`, `artifact_filename`, `card` JSONB,
`workspace_key` (canonical workspace block, or NULL), `source_session_id`,
`source_slot`, `created_by`, `created_at`, `committed_at`.

Constraints: UNIQUE `(app_id, version)` (the full SemVer text is the identity),
UNIQUE `(app_id, sha256)`. Indexes: `(app_id, precedence_key, created_at)`;
`sha256`; `workspace_key` (partial, NOT NULL); `created_at` (partial, pending).

### `canvas_app_editors` — new

Contributors on shared apps: `(app_id FK cascade, user_id FK users, granted_by, granted_at)`,
PK `(app_id, user_id)`, index on `user_id`. Same shape as `agent_package_editors` (0063).

### `canvas_app_tombstones` — new

`app_id` PK, `artifact_session_id`, `name`, `deleted_at`, `purged_at`. Written by
delete so an interrupted byte deletion can be finished by the prune op.

### `canvas_app_loads` — new

`load_id BIGSERIAL` PK, `app_id` FK cascade, `app_name`, `version`, `version_id`,
`session_id`, `user_provider`, `user_subject`, `loaded_at`.
Indexes: `(app_id, loaded_at DESC, load_id DESC)`, `(loaded_at)`.

### `canvas_workspace_grants` — new

The session owner's positive decision on one exact workspace program. PK
`(session_id, slot, page_sha256, declaration_sha256, bindings_sha256,
owner_provider, owner_subject)`; `rev` (the revision the owner saw), `trust`,
`version_id`, `decision` (`granted`|`denied`), `decided_by_provider`,
`decided_by_subject`, `decided_at`. Every new program asks once, whoever wrote
it; the identical program redrawn in the same slot keeps its decision; a new
session owner decides again. An ownerless session's grants use the empty
owner.

## Function changes (all new)

| Function | Purpose |
|---|---|
| `cms_canvas_app_semver_parts(text)` | SemVer 2.0 grammar (build metadata included); NULL when invalid |
| `cms_canvas_app_precedence_key(text)` | text whose "C" order equals SemVer precedence; every number is a 4-digit length then its digits (no truncation; components over 9,999 digits are unorderable and refused as `BAD_VERSION`); build metadata ignored |
| `cms_canvas_app_semver_next_patch(text)` | `semver.inc(v, 'patch')` |
| `cms_canvas_app_is_owner(app, provider, subject)` | |
| `cms_canvas_app_is_editor(app_id, provider, subject)` | |
| `cms_canvas_app_resolve_id(name, viewer…, resource_admin, selector…)` | visible copy only; own copy shadows shared |
| `cms_canvas_app_authz(…, level)` | `read` / `editor` / `owner`; invisible ⇒ `CANVAS_APP_NOT_FOUND`, visible ⇒ `CANVAS_APP_FORBIDDEN` |
| `cms_canvas_app_finish_import(app_id)` | an import that created its app is finished; later imports keep the pointer |
| `cms_canvas_app_find_version(app_id, version)` | exact version text, else the single version with that precedence |
| `cms_canvas_app_sha_hidden(sha, viewer…)` | bytes of a private app the viewer may not see |
| `cms_canvas_app_foreign_bytes(sha, workspace key, viewer…)` | the read guard (defense in depth): the name of another owner's app whose exact bytes or workspace block these are and that the viewer may not edit, `(private)` for a private one; NULL otherwise. NULL-safe: an ownerless viewer owns and edits nothing |
| `cms_canvas_app_is_space(id)` | an app byte space, live or deleted |
| `cms_canvas_app_reserve(…)` | create-or-lock the app (insert, catch unique violation, re-lock), same-bytes no-op, version choice, pending row. Metadata (description/tags) changes only on a publish, never on an import. The ownerless (legacy migration) path may extend only an ownerless app (`NAME_TAKEN` otherwise) |
| `cms_canvas_app_commit(version_id, may_activate)` | pending → ready under the app's row lock; activate only when higher than every other ready version (`COLLATE "C"`), so a pinned lower version is not replaced by a publish below the latest. A version that is not pending is returned unchanged (idempotent; never moves the active pointer) |
| `cms_canvas_app_abort(version_id)` | delete a pending row |
| `cms_canvas_app_list(viewer…)` | visible apps; disabled ones only for owner, contributors, resource admin |
| `cms_canvas_app_search(viewer…, query, limit)` | ranked full-text over name, tags, description |
| `cms_canvas_app_get(…)` | one app with ready versions |
| `cms_canvas_app_get_version(…, version)` | the version to draw or download; `CANVAS_APP_DISABLED` for others |
| `cms_canvas_app_match_by_sha(sha, viewer…)` | visible ready versions with these bytes |
| `cms_canvas_app_foreign_workspace_match(key, viewer…)` | another owner's shared version declares this workspace block |
| `cms_canvas_app_set_enabled`, `_set_metadata`, `_pin` | editor level |
| `cms_canvas_app_set_scope`, `_delete` | owner level; making private revokes contributors; delete writes a tombstone |
| `cms_canvas_app_grant_editor`, `_revoke_editor`, `_list_editors` | shared apps; owner or admin |
| `cms_canvas_app_record_load` | one row; deletes ≤ 200 rows older than 400 days |
| `cms_canvas_app_list_loads` | owner or resource admin; cursor `(loaded_at, load_id)`; `total_30d` |
| `cms_canvas_app_prune_loads(older_than, batch)` | batch delete of expired rows |
| `cms_canvas_app_prune_pending(older_than)` | LIST stale pending rows (version id, space, file; at most 1,000). The pruner deletes the bytes first and then aborts each row, so a storage failure leaves the row to retry |
| `cms_canvas_app_list_tombstones`, `_mark_purged` | finish interrupted deletes |
| `cms_canvas_workspace_set_grant`, `_get_grant` | workspace approval per exact program: session, slot, page/declaration/bindings sha256 and session owner; the setter refuses a non-hex key |

Errors are raised as `CANVAS_APP_<CODE>: <message>`; `CanvasAppStore` maps
`<CODE>` to the public code (`DISABLED` → `APP_DISABLED`).
