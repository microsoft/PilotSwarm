## Function changes

### `cms_steer_record_resend_intent(p_session_id, p_request_id, p_client_message_id, p_actor, p_sender)` — new

- `invalid`: empty client message id or no canonical actor.
- `not_found`: the request is not in this session.
- Existing `(session, client_message_id)`: same request and same resender ⇒ `recorded` with
  `duplicate: true` and the stored linkage; any other mapping ⇒ `conflict` (no fields disclosed).
- New id: the request must be closed or withdrawn with disposition `not_delivered_turn_ended`,
  `not_delivered_turn_stopped` or `withdrawn`; otherwise `not_resendable`. Inserts the link and, in
  the same transaction, the event `session.steering_resend_requested`
  `{ schemaVersion: 1, requestId, clientMessageIds: [id], actor, sender }`.
- Never enqueues anything; the caller then performs the ordinary send with the same client message id.
