# Diff for migration 0084

Migration: `migrations/compute-targets-0084.ts`, function `computeTargetsMigration`, registered as `0084 compute_targets`.
Design: `docs/proposals/compute-providers.md`.

Additive. No existing table, column or function changes. A session records its compute target in `sessions.creation_config` (keys `computeTarget` and `computeTargetId`, migration 0072); no session column is added.

Two tables: the compute targets people pick and the host bindings PilotSwarm is using. Neither holds a secret.

## New table: compute targets

| Table | Columns |
|---|---|
| `compute_targets` | `name TEXT PRIMARY KEY`, `target_id UUID UNIQUE` (never reused), `kind TEXT`, `class TEXT ('shared','personal')`, `owner_user_id BIGINT → users`, `display_name TEXT`, `config JSONB` (an object), `enabled BOOLEAN DEFAULT TRUE`, `created_by BIGINT`, `created_at`, `updated_at` |

Constraints: a shared target has no owner and a personal one always has one; `kind` matches `^[a-z0-9][a-z0-9-]{0,63}$`; `config` is a JSON object.

`name` is `<owner>/<label>` — `^[a-zA-Z0-9][a-zA-Z0-9._%+@-]{0,126}/[a-zA-Z0-9][a-zA-Z0-9._-]{0,63}$` — so a target is named after whoever owns it and two people's labels never collide. A shared target, and only a shared target, is in the `shared/` space (`compute_targets_name_space`). For a personal target the create procedure also checks the owner part against the actor's own sign-in address, so no caller can name a target after anyone else; an actor with no address on record is refused. 

Index: `compute_targets_owner (owner_user_id) WHERE owner_user_id IS NOT NULL`.

## New table: host bindings

One row per (session tree, target, host): what PilotSwarm is using now, and what it has finished with.

| Table | Columns |
|---|---|
| `compute_bindings` | `binding_id UUID PRIMARY KEY`, `root_session_id TEXT`, `target_id UUID`, `kind TEXT`, `host_key TEXT`, `host_ref JSONB`, `worker_node_id TEXT`, `leased_until TIMESTAMPTZ`, `released_at TIMESTAMPTZ`, `done_at TIMESTAMPTZ`, `done_attempt_at TIMESTAMPTZ`, `created_at`, `updated_at` |

A worker takes a lease when it binds and renews it while it holds the binding, so a provider reads renewals that stop as "nobody is using this host" — which covers a worker that crashed or was taken away as well as one that let go properly. `released_at` says a worker let go; `done_at` says the session tree is finished with the host for good, which is the notice a provider gets exactly once. Neither means destroy: what happens to a host nobody needs is the provider's decision alone.

`host_key` is the provider's own id for the host plus which incarnation of it, so a replaced host is a different binding; `host_ref` is the provider's opaque handle and PilotSwarm never reads inside it. No handshake secret is ever written here.

Constraints: `host_ref` is a JSON object; `(root_session_id, target_id, host_key)` is unique. Index: `compute_bindings_unfinished (root_session_id) WHERE done_at IS NULL`.

| Function | Role |
|---|---|
| `cms_compute_binding_record(p_root_session_id, p_target_id, p_kind, p_host_key, p_host_ref, p_worker_node_id, p_lease_ms)` | At bind: write the binding and take a lease. Upserts, so the sessions of a tree share one row. |
| `cms_compute_binding_renew(p_binding_id, p_worker_node_id, p_lease_ms)` | On the lease timer. False when the binding is gone or already finished with. |
| `cms_compute_binding_release(p_binding_id)` | A worker is no longer using the host. The row stays: only the end-of-session notice closes a binding. |
| `cms_compute_binding_claim_done(p_worker_node_id, p_limit, p_retry_after_ms)` | The sweep: bindings whose session tree has ended, is deleted, or has no row at all, claimed with `FOR UPDATE SKIP LOCKED` and stamped with the attempt. |
| `cms_compute_binding_mark_done(p_binding_id)` | The provider has been told. Idempotent: only the first notice counts. |
| `cms_compute_binding_list(p_root_session_id)` | The bindings of one session tree. |

Refusal: `COMPUTE_BINDING_INVALID`.

`cms_compute_target_by_id(p_target_id)` is added alongside: the target with an id, whoever owns it, for work PilotSwarm does for itself (telling a provider a tree it no longer knows about is finished with a host). Trusted caller; nothing that answers a user goes through it.
