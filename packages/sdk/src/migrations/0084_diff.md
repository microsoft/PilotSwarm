# Diff for migration 0084

Migration: `migrations/compute-targets-0084.ts`, function `computeTargetsMigration`, registered as `0084 compute_targets`.
Design: `docs/proposals/compute-providers.md`.

Additive. No existing table, column or function changes. A session records its compute target in `sessions.creation_config` (keys `computeTarget` and `computeTargetId`, migration 0072); no session column is added.

One table: the compute targets people pick. It holds no secret.

Nothing records which host a session is on. A host is held while a session uses it, and the PilotSwarm component on a host ends itself after a set time with no connection, so nothing has to be written down to know a host is free.

## New table: compute targets

| Table | Columns |
|---|---|
| `compute_targets` | `name TEXT PRIMARY KEY`, `target_id UUID UNIQUE DEFAULT gen_random_uuid()` (never reused), `kind TEXT`, `class TEXT DEFAULT 'shared' CHECK (class IN ('shared'))`, `display_name TEXT`, `config JSONB` (an object), `enabled BOOLEAN DEFAULT TRUE`, `created_by BIGINT`, `created_at`, `updated_at` |

Constraints: `kind` matches `^[a-z0-9][a-z0-9-]{0,63}$`; `config` is a JSON object.

`name` is `<owner>/<label>` — `^[a-zA-Z0-9][a-zA-Z0-9._%+@-]{0,126}/[a-zA-Z0-9][a-zA-Z0-9._-]{0,63}$`. Today every target is a shared one an administrator registers for everyone, so the owner part is always `shared` (`compute_targets_name_space`), and the worker writes that part itself — it is never taken from a request. Keeping the owner part in the name now means targets with another owner can be added later without renaming anything. Targets people register for themselves are future work (`docs/proposals/compute-providers.md`, section 12); nothing in this migration carries an owner.

## New functions: compute targets

| Function | Role |
|---|---|
| `cms_compute_target_create(p_name, p_kind, p_display_name, p_config, p_actor, p_is_admin)` | Registers a shared target. Only an administrator. |
| `cms_compute_target_assert_manage(p_name, p_actor, p_is_admin)` | The target, if the actor may change it. Only an administrator. |
| `cms_compute_target_update(p_name, p_display_name, p_config, p_enabled, p_actor, p_is_admin)` | NULL arguments keep the current value. |
| `cms_compute_target_delete(p_name, p_actor, p_is_admin) RETURNS BIGINT` | Deletes; returns how many sessions that can still take a turn use it (by id). A session in a state it never leaves — completed, failed or cancelled — is not counted. |
| `cms_compute_target_list(p_viewer, p_is_admin)` | Every target, with `manageable` and `target_id`. `config` is empty unless the viewer may manage it. |
| `cms_compute_target_assert_session(p_name) RETURNS UUID` | Session creation check: the target exists and is enabled. Returns the target id the session records. |
| `cms_compute_target_resolve_for_session(p_target_id)` | Worker side, before every turn: the target with that id, or no row. Disabled rows are returned so the worker can say so. |

Refusals are raised as `COMPUTE_TARGET_INVALID`, `COMPUTE_TARGET_FORBIDDEN`, `COMPUTE_TARGET_NOT_FOUND`, `COMPUTE_TARGET_CONFLICT` and `COMPUTE_TARGET_DISABLED`.
