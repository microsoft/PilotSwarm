# Diff for migration 0084

Migration: `migrations/compute-targets-0084.ts`, function `computeTargetsMigration`, registered as `0084 compute_targets`.
Design: `docs/proposals/compute-providers.md`.

Additive. No existing table, column or function changes. A session records its compute target in `sessions.creation_config` (keys `computeTarget` and `computeTargetId`, migration 0072); no session column is added.

## New table

| Table | Columns |
|---|---|
| `compute_targets` | `name TEXT PRIMARY KEY`, `target_id UUID UNIQUE` (never reused), `kind TEXT`, `class TEXT ('shared','personal')`, `owner_user_id BIGINT → users`, `display_name TEXT`, `config JSONB` (an object), `enabled BOOLEAN DEFAULT TRUE`, `created_by BIGINT`, `created_at`, `updated_at` |

Constraints: a shared target has no owner and a personal one always has one; `name` matches `^[a-zA-Z0-9][a-zA-Z0-9._-]{0,63}$`; `kind` matches `^[a-z0-9][a-z0-9-]{0,63}$`; `config` is a JSON object.

Index: `compute_targets_owner (owner_user_id) WHERE owner_user_id IS NOT NULL`.

## New functions

| Function | Role |
|---|---|
| `cms_compute_target_in_namespace(p_name, p_viewer)` | The target if it is shared or the viewer's own; otherwise no row. |
| `cms_compute_target_create(p_name, p_kind, p_class, p_display_name, p_config, p_actor, p_is_admin)` | Shared needs an admin. A personal target always belongs to the actor. |
| `cms_compute_target_assert_manage(p_name, p_actor, p_is_admin)` | A personal target answers only to its owner (reads as absent to anyone else, admins included); a shared one needs an admin. |
| `cms_compute_target_update(p_name, p_display_name, p_config, p_enabled, p_actor, p_is_admin)` | NULL arguments keep the current value. |
| `cms_compute_target_delete(p_name, p_actor, p_is_admin) RETURNS BIGINT` | Deletes; returns how many open sessions still use it (by id). |
| `cms_compute_target_list(p_viewer, p_is_admin)` | Every shared target plus the viewer's own, with `manageable`. `config` is empty unless `manageable`. |
| `cms_compute_target_assert_session(p_name, p_owner_provider, p_owner_subject, p_is_system) RETURNS UUID` | Session creation check: shared, or the owner's own (system sessions: shared only), and enabled. Returns the target id the session records. |
| `cms_compute_target_resolve_for_session(p_target_id, p_owner_provider, p_owner_subject, p_is_system)` | Worker side, before every turn: the target with that id if the owner may still use it; otherwise no row. |

Refusals are raised as `COMPUTE_TARGET_INVALID`, `COMPUTE_TARGET_FORBIDDEN`, `COMPUTE_TARGET_NOT_FOUND`, `COMPUTE_TARGET_CONFLICT` and `COMPUTE_TARGET_DISABLED`.
