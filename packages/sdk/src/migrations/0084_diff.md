# Migration 0084: Message of the day

Adds deployment-wide `motds` with UTC windows, markdown, two optional 2 MB
pictures, creator identity and retry IDs. Adds `motd_dismissals` keyed by user
and message. There is no foreign key to messages: deleting a message removes
its pictures and retry record but keeps dismissals. Identity IDs are not reused.

The `cms_motd_*` functions enforce authenticated reads and dismissals, and
admin-only create, list and delete. Current reads apply the time window and
viewer dismissals in SQL. Overlaps use descending from-time, creation time,
then message ID. History is bounded and supports an older-ID cursor.

No audit record is written. No profile settings or existing rows are changed.
Current reads omit the creator's identity. Ordinary image reads require an
active time window. Admin image reads also support scheduled and ended previews.
