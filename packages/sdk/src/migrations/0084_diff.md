# Diff for migration 0084

Migration: `migrations/compute-targets-0084.ts`, function `computeTargetsMigration`, registered as `0084 compute_targets`.
Design: `docs/proposals/compute-providers.md`.

Additive. No existing table, column or function changes. A session records its compute target in `sessions.creation_config` (keys `computeTarget` and `computeTargetId`, migration 0072); no session column is added.

## New table

| Table | Columns |
|---|---|
| `compute_targets` | `name TEXT PRIMARY KEY`, `target_id UUID UNIQUE` (never reused), `kind TEXT`, `class TEXT ('shared','personal')`, `owner_user_id BIGINT → users`, `display_name TEXT`, `config JSONB` (an object), `enabled BOOLEAN DEFAULT TRUE`, `advertised JSONB` (an object, or NULL), `advertised_at TIMESTAMPTZ`, `created_by BIGINT`, `created_at`, `updated_at` |

Constraints: a shared target has no owner and a personal one always has one; `kind` matches `^[a-z0-9][a-z0-9-]{0,63}$`; `config` and `advertised` are JSON objects.

`name` is `<owner>/<label>` — `^[a-zA-Z0-9][a-zA-Z0-9._%+@-]{0,126}/[a-zA-Z0-9][a-zA-Z0-9._-]{0,63}$` — so a target is named after whoever owns it and two people's labels never collide. A shared target, and only a shared target, is in the `shared/` space (`compute_targets_name_space`). For a personal target the create procedure also checks the owner part against the actor's own sign-in address, so no caller can name a target after anyone else; an actor with no address on record is refused. The label holds no colon, which is what keeps a target's name separable from a model's.

`advertised` is what the target last said it offers (its models, operating system and other facts), and `advertised_at` is when. It comes from the host, which is untrusted: it decides which options a user is shown, never what anyone is allowed to do.

Index: `compute_targets_owner (owner_user_id) WHERE owner_user_id IS NOT NULL`.

## New functions

| Function | Role |
|---|---|
| `cms_compute_target_in_namespace(p_name, p_viewer)` | The target if it is shared or the viewer's own; otherwise no row. |
| `cms_compute_target_create(p_name, p_kind, p_class, p_display_name, p_config, p_actor, p_is_admin)` | Shared needs an admin. A personal target always belongs to the actor, and must be named after them. |
| `cms_compute_target_assert_manage(p_name, p_actor, p_is_admin)` | A personal target answers only to its owner (reads as absent to anyone else, admins included); a shared one needs an admin. |
| `cms_compute_target_update(p_name, p_display_name, p_config, p_enabled, p_actor, p_is_admin)` | NULL arguments keep the current value. |
| `cms_compute_target_delete(p_name, p_actor, p_is_admin) RETURNS BIGINT` | Deletes; returns how many open sessions still use it (by id). |
| `cms_compute_target_list(p_viewer, p_is_admin)` | Every shared target plus the viewer's own, with `manageable`, `target_id` and what it advertises. `config` is empty unless `manageable`. |
| `cms_compute_target_assert_session(p_name, p_owner_provider, p_owner_subject, p_is_system) RETURNS UUID` | Session creation check: shared, or the owner's own (system sessions: shared only), and enabled. Returns the target id the session records. |
| `cms_compute_target_resolve_for_session(p_target_id, p_owner_provider, p_owner_subject, p_is_system)` | Worker side, before every turn: the target with that id if the owner may still use it; otherwise no row. |

Refusals are raised as `COMPUTE_TARGET_INVALID`, `COMPUTE_TARGET_FORBIDDEN`, `COMPUTE_TARGET_NOT_FOUND`, `COMPUTE_TARGET_CONFLICT` and `COMPUTE_TARGET_DISABLED`.

`cms_compute_target_record_advertisement(p_target_id, p_advertised)` stores what a target advertises (worker side; drops `models` for a shared target).
